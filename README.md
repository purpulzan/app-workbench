# App Workbench

Proyecto personal en fase inicial para desarrollar aplicaciones web,
integraciones de APIs y herramientas de productividad.

## Objetivo

Construir un prototipo que permita organizar tareas y notas, buscar
información y resumir documentos aportados por el usuario.

## Uso previsto de Claude

Integrar Claude mediante API para experimentar con:

- Resúmenes de notas y documentos.
- Clasificación y organización de información.
- Un asistente conversacional dentro de la aplicación.
- Asistencia durante el desarrollo y las pruebas de software.

Las primeras pruebas serán personales, con datos de ejemplo,
antes de considerar una versión para otros usuarios.

## Estado actual

Fase de planificación y prototipado. Las funcionalidades descritas
son objetivos de desarrollo y todavía no están implementadas.
